# 코드 경고 및 이미지 로딩 최적화 완료

점검 기간: 2026-09-18~19. 기능 수정 커밋: `3eee7e2`.

## 적용 범위

- `stayhalong.com` 임시 홈, 공식 홈, 공통 헤더·푸터·홈 라우팅 파일은 이번 수정에서 변경하지 않았다.
- 임시 홈의 390px·1440px 수정 전후 화면 캡처를 비교했으며 픽셀 차이는 각각 0이었다. 상단 메뉴를 추가하거나 기존 링크 상태를 변경하지 않았다.
- 임시 홈 동결 지침을 `AGENTS.md`에 반영했다.
- 기존 플랫폼 저장소, DB, RLS, 결제 API 및 원본 이미지 파일은 변경하지 않았다.

## 경고 5건 수정

- 관리자 공개 이미지 미리보기는 화면 크기에 맞춘 `CatalogImage`로 변경했다. 허용된 공개 이미지에만 Next.js 최적화를 적용하고 기존 이미지 오류 표시를 유지했다.
- 관리자 첨부 캡처는 크기가 지정된 `next/image`와 지연 로딩으로 변경했다. 서명된 비공개 주소는 공유 이미지 캐시를 통과하지 않도록 직접 전달한다.
- 상품 상세의 장바구니 이동 2곳은 저장 성공을 확인한 뒤 `router.push()`로 이동하도록 변경했다.
- 회원가입 후 세션이 있는 경우 `router.push()`와 `router.refresh()`로 이동한다. 이메일 인증이 필요한 경우의 안내는 유지했다.
- 경고를 숨기는 ESLint 예외나 규칙 비활성화는 추가하지 않았다.

## 이미지 개선

공개 CDN에서 받은 수 MB 원본을 작은 카드와 썸네일에도 그대로 표시하던 구조를 수정했다. 목록·상세·객실·확대 사진은 표시 크기에 맞게 요청하고, 확대창 썸네일은 가로 스크롤 영역에 가까워졌을 때 요청한다. 대표 사진은 우선 로딩한다. 기존 분류, 모든 사진의 접근 경로, 확대·다음 사진·닫기 동작은 유지한다.

모바일 390×900, DPR 1, 브라우저 캐시 비활성화 상태의 초기 이미지 전송량:

| 화면 | 수정 전 | 수정 후 | 감소율 |
| --- | ---: | ---: | ---: |
| 크루즈 목록 | 8,885,897 B | 60,515 B | 99.3% |
| 호텔 목록 | 5,265,748 B | 40,491 B | 99.2% |
| 바야 소울 크루즈 상세 | 14,745,444 B | 106,779 B | 99.3% |
| 더 야트 호텔 상세 | 2,551,464 B | 40,490 B | 98.4% |

전체 스크롤 후 크루즈 목록의 전송량도 38,956,758 B에서 325,884 B로 감소했다. 데스크톱 1440px에서는 위 4개 화면의 초기 이미지 전송량이 각각 98.4%, 97.4%, 98.9%, 91.3% 감소했다.

200,000 B/s 다운로드 속도와 80ms 지연을 모의한 동일 대표 이미지 1장 비교에서는 원본 12.86초, 이미 변환 캐시가 생성된 축소 이미지 0.137초였다. 이는 페이지 전체 로딩 시간이나 실제 고객의 평균 속도가 아니다.

최초 이미지 변환에는 서버 처리 시간이 추가된다. 고속 로컬 환경의 첫 크루즈 목록 측정에서는 네트워크 안정화까지의 시간이 3.26초에서 4.27초로 늘었다. 따라서 이번 결과는 전송량 감소와 캐시된 이미지의 로딩 개선으로 해석해야 하며, 운영 환경의 첫 방문·재방문 속도와 이미지 변환 사용량은 배포 후 별도 관찰 대상이다.

## 검증

- 프로덕션 빌드 및 전체 ESLint `--max-warnings 0` 확인.
- 홈페이지 회귀 검사 58건: 실패 0건.
- 이미지 전후 비교 4개 화면 × 2개 화면 폭: 각 8건 통과.
- 목록 전체 스크롤, 상세 확대창, 다음 사진, Escape 닫기, 이미지 오류, 브라우저 실행 오류, 가로 넘침 확인.
- 9월 19일 운영 URL 읽기 확인: `stayhalong.com/` HTTP 200 및 상단 주요 메뉴 없음. `shthome.stayhalong.com/cruises` HTTP 200, 상품 사진 24개 모두 최적화 이미지 주소 사용. 이 확인은 배포 커밋 SHA 또는 운영 전체 흐름 검증을 대신하지 않는다.
- 관리자 로그인 후 실제 저장과 실계정 회원가입·예약 생성은 실행하지 않았다. 변경한 회원가입·장바구니 이동의 실계정 전체 흐름은 별도 검증 범위다.

## 재실행 및 증거

빌드 후 `node node_modules/next/dist/bin/next start --port 3100`으로 실행하고:

```powershell
node node_modules/eslint/bin/eslint.js . --max-warnings 0
node scripts/image-performance-audit.mjs http://localhost:3100 .migration-audit/image-after
```

- `.migration-audit/image-after/report.json`
